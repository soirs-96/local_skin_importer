# 排位战绩评分机制 —— 设计文档

日期:2026-11-13
范围:`local_skin_importer`(Electron 桌面端),纯本地实现

## 要解决的问题

段位只说明「你在哪个池子里」,不说明「你在池子里排第几」。同一个黄金段位里,
既有carry全局的,也有挂机送分的。战绩查询页现在只给 KDA 和胜负,看不出强弱。

目标:给排位战绩加一套评分机制,让同一个段位的人能分出高低。

## 口径:绝对分为主 + 同场对比

- **绝对分**:每个指标跟**该位置的基准值**比,换算成 0~1 的子分,等权平均,乘 10 得到 0~10 分。
- **同场对比**:这一局十个人都打了分,「我比同场平均高多少分」是真实存在的差值。

**不给「超过了 X% 的同段位玩家」这种说法** —— 那需要一个人群基线库,
本地算不出来,写了就是假数据。这是这一版刻意砍掉的东西。

## 为什么需要「位置基准表」

如果直接按「经济份额」在同场十个人里排名,辅助永远垫底 —— 辅助的经济份额
天然就是全队最低(10% 左右),射手是 25%。这不是水平差异,是角色差异。

所以每个位置要有自己的期望值,先除以基准值再比。

## 位置判定

腾讯的 participant 带两个字段:`lane`(载入时的分路)和 `role`(定位)。

| 优先级 | 条件 | 结果 |
|---|---|---|
| 1 | `role === 'SUPPORT'` | 辅助 |
| 2 | `lane === 'JUNGLE'` | 打野 |
| 3 | `lane === 'MIDDLE'` | 中单 |
| 4 | `lane === 'TOP'` | 上单 |
| 5 | `lane === 'BOTTOM'` | 射手 |
| 6 | `role === 'SOLO'` | 中单 |
| 7 | `role === 'CARRY'` | 射手 |
| 8 | 都认不出 | **UNKNOWN**(不猜) |

辅助排第一位是因为辅助玩家爱抢中路,`lane` 常写成 MIDDLE,但他确实是辅助。

大乱斗一律 UNKNOWN —— 那边的 `lane` 和 `role` 都是乱的。

## 指标

四个,都算队内份额,所以跟队伍长短无关:

```
参团率 KP = (击杀 + 助攻) / 队伍总击杀
经济份额   = goldEarned / 队伍总经济
伤害份额   = 伤害 / 队伍总伤害
KDA        = (击杀 + 助攻) / max(死亡, 1)
```

补刀份额算出来**展示但不进分数** —— 它和经济份额高度相关,再加一份等于把经济算两遍。

### 基准表(估算值)

| | KP | 经济份额 | 伤害份额 | KDA |
|---|---|---|---|---|
| 中单 | 0.60 | 0.25 | 0.26 | 3.4 |
| 打野 | 0.68 | 0.18 | 0.15 | 3.8 |
| 射手 | 0.55 | 0.25 | 0.30 | 3.5 |
| 上单 | 0.55 | 0.18 | 0.18 | 3.2 |
| 辅助 | 0.72 | 0.10 | 0.07 | 3.8 |
| 未知 | 0.60 | 0.20 | 0.20 | 3.5 |

这些是**模型参数**,按常规排位(黄金~铂金)的常见水平估的。方向没问题,具体数字
肯定有偏差 —— 后端把真实对局数据汇起来之后可以自动校准这张表。

## 算分

1. `ratio = 实际值 / 基准值`,先夹到 [0.25, 4]
2. `子分 = clamp(0.5 + 0.25·log₂(ratio), 0, 1)`
   - ratio = 1 → 0.5 分;2 倍 → 0.75;4 倍 → 1.0;一半 → 0.25;四分之一 → 0
3. 四项等权平均(各 0.25)→ `composite ∈ [0,1]`
4. **本局分 = composite × 10**

四项等权,角色差异全靠基准表吸收 —— 不再搞第二张角色权重表。

### 边界

- 队伍 0 击杀时 KP 记成该位置的基准值(不奖不罚)。记 0 的话被团灭的一方整队归零,
  而那一局的问题不在「没参团」,在「被团灭了」。
- 非召唤师峡谷的局不打分。
- 人数少于 5 个的局不打分(不是一场完整的对局)。

## 聚合

- **只统计排位**:召唤师峡谷(mapId 11)且队列 ∈ {400, 420, 440}。
  大乱斗、极限闪击、普通匹配一律不算。
- **近期表现分** = 各局本局分的平均。
- **比同场平均高/低** = 各局 `(我的本局分 − 同场十人平均分)` 的平均。
- **分位置均分**:一个人会玩不同位置,按位置分组统计,主位置 = 场次最多的那个。

## 界面

1. **战绩查询页**:资料卡(段位)下面新增「表现分」卡
   - 大数字(近期表现分)+ 同场对比 + 主位置
   - 四条分维度细条:条形是子分,右边是原始指标值
   - 补刀份额单独一行(不计入分数)
   - 位置不唯一时给分位置小表
2. **每行对局**:加一列「本局分」和名次(如 `3/10`)
3. **展开的十人面板**:每人名字后面标他的本局分

## 这一版不做

- 不给百分位 /「超过多少人」—— 要人群基线,本地做不了
- 不接后端、不存历史、不改 lolskin 主站
- 不算大乱斗 / 普通匹配

## 测试

- 位置判定的每条优先级
- 子分曲线(1 → 0.5、2 → 0.75、4 → 1、0.25 → 0、0 → 0)

- 名次按分数排
