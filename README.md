# LOL 皮肤助手 · 皮肤导入使用指南

> 桌面端把**你电脑上的英雄联盟皮肤库存**导入到「LOL皮肤鉴赏」微信小程序，
> 手机上随时能看到自己的收藏册和皮肤库。

---

## 一、这是什么

**LOL 皮肤助手**（安装包名 `LOL Skin Importer`）是一个 Windows 桌面小工具，
它做两件事：

1. **皮肤同步** —— 读取你本机英雄联盟客户端的库存，把「你拥有的皮肤」上传到服务器，
   这样微信小程序里的**我的皮肤收藏册**、**我的皮肤库**才有内容。
2. **对局助手** —— 选人阶段根据位置给推荐、查看段位和最近战绩（附加功能，见第十节）。

小程序本身管的是**皮肤鉴赏**：官方分级、原画、评分、社区讨论。
桌面端管的是**「我到底有哪些皮肤」** —— 这份数据在游戏里没有统一视图，
只能从客户端里读出来再同步过去。两边合起来才是完整的皮肤库体验。

---

## 二、装好之后小程序里多了什么

| 小程序入口 | 内容 |
|---|---|
| 我的 → **我的皮肤收藏册** | 收集完成度百分比、已拥有 X / Y、每个英雄的皮肤收集进度条 |
| 我的 → **我的皮肤库** | 全部皮肤逐条列表，已拥有 / 未拥有可切换，可按官方分级、奖池筛选搜索 |

收藏册顶部会显示「上次同步」，一眼能看出数据是不是新的。

## 三、使用前提

- **Windows 64 位**（Windows 10 / 11）
- **英雄联盟客户端**已安装并登录了账号
  - **只支持国服客户端**（WeGame 版 / 腾讯代理下的英雄联盟）。国际服客户端不在支持范围内。
- **微信小程序「LOL皮肤鉴赏」**账号
- 首次同步会**把当前登录的 LOL 账号和你的小程序账号绑定**，之后不能再换（见第九节 Q7）

## 四、安装

安装包在仓库的 `release/<版本号>/` 目录下，文件名形如：

```
LOL Skin Importer-0.2.1-x64.exe
```

双击运行 → 一路 `下一步` → `安装` → `完成`。

安装程序会创建**桌面快捷方式**和**开始菜单**快捷方式（`LOL Skin Importer`）。
装完不用改任何设置，也**不需要管理员权限**。

> 想确认自己是什么版本：打开应用，登录页或同步页最下面有一行很淡的版本号，
> 点它可以打开开发者面板。版本号直接来自安装包，界面上显示的就是你手上的这个包。

> 报问题时先点版本号进开发者面板 → **复制诊断信息**，把那段文字发给维护者。
> 里面有**应用版本**和**客户端失败分类码**，能直接定位是哪一类问题，省掉一轮来回。

## 五、首次同步：三步走

### 第 1 步 · 在小程序里拿同步码

打开微信 → 搜小程序「**LOL皮肤鉴赏**」→ 底部 **我的** → 菜单里点 **🔗 获取桌面同步码**。

会弹出一个 **6 位数字**，下面有倒计时。

> 同步码规则：**5 分钟内有效**、**30 秒内不能重复生成**、**一个码只能用一次**。
> 过期了或者用过了，回小程序再点一次重新生成就行。

### 第 2 步 · 在桌面端登录

启动 **LOL 皮肤助手**，点右上角 **登录**（或直接打开就是登录页）。

在「同步码」输入框里填小程序上那 6 位数字 → **登录**。

成功后右上角会变成 **已登录**，登录信息保存在本机，
用操作系统的加密存储（Windows DPAPI）落盘，**有效期 30 天**。

### 第 3 步 · 同步皮肤

切到 **皮肤同步** 页，从上往下：

| 区域 | 做什么 | 说明 |
|---|---|---|
| 游戏客户端 | 点 **检测客户端** | 绿点 = 已连上；会显示当前 LOL 账号名 |
| 已拥有皮肤 | 点 **读取我的皮肤** | 读出你有几款皮肤，数字是金色大字 |
| 皮肤图鉴 | 点 **浏览图鉴** | 桌面端就能翻全部皮肤，**你已经拥有的会高亮**，还能按名称 / 英雄 / 官方分级筛，也能「只看还没拥有的」 |
| 同步到小程序 | 点 **立即同步** | 成功后显示「新增 N 款 · 更新 N 款 · 当前共 N 款」 |

**小技巧**：游戏客户端已经在跑、而且你已经登录了的话，**每次打开桌面端它会自动同步一次**，
不用手点。自动同步失败是静默的（不弹窗打扰你），想确认就手动点一次「立即同步」。

## 六、同步完在小程序里看什么

1. 打开小程序 → **我的** → **我的皮肤收藏册**
2. 顶部大数字是**收集完成度**，下面是 **已拥有 X / Y**
3. 下面按英雄排卡片墙，每张卡是 `已拥有 / 总数` + 一条进度条
4. 点右上角 **查看全部皮肤** 进 **我的皮肤库**，可以逐条翻全部皮肤、切「已拥有 / 未拥有」

如果还是显示「还没有皮肤数据」，说明这一步还没同步成功 —— 回到第九节排查。

## 七、数据是怎么算的（别误解「已拥有 X / Y」）

这块最容易被误会，说清楚：

- **读的是游戏客户端的库存接口**，所以**已下架（绝版）的皮肤也能同步到**。
  商城目录做不到这点 —— 绝版皮肤在商城里已经下架了。
- 商城目录只当**降级兜底**。它本质是**商品目录**，里面混着云顶棋盘、英雄礼包、
  货币、蛋，全都被标成 `CHAMPION_SKIN`，拿来当「什么是皮肤」会把这些噪声算进来。
- 上传前会跟**站内图鉴取交集**，滤掉炫彩、皮肤变体、经典版英雄的长 id。
- **每个英雄的默认皮肤不算「可收集皮肤」**，游戏客户端的收藏册也不计，规则保持一致。

所以你的「已拥有 X / Y」跟游戏客户端收藏册**可能差一点点**，
差额通常是**经典版英雄皮肤卡**（站内不作为可收集皮肤收录）。这是口径差异，不是 bug。

界面上有个来源标签可以直接看出这次读的是哪条路径：

- **实时读取自游戏客户端**（蓝色）= 库存口径，权威
- **备用来源(降级)**（金色）= 库存接口读不到，退到了商城目录，**会漏绝版皮肤**

## 八、隐私说明

- **只上传三样东西**：账号唯一标识（PUUID）、召唤师名、你拥有的皮肤 id 列表。
- **不上传**账号密码、不上传截图、不上传聊天记录、不读取游戏内其他数据。
- 客户端全程只跟**本机的游戏客户端**（`127.0.0.1`）通信，数据不出你的电脑，
  只有同步那一刻才把上面那三样发到我们的服务器。
- 登录令牌用 **Windows 系统加密**存在本机，不落明文。
- 我们**不提供也不需要**任何充值、交易、转账功能。

## 九、常见问题

### Q1 · 「检测客户端」一直不绿 / 连不上游戏客户端

**英雄联盟客户端必须已经登录到召唤师、进到主界面**（能看到英雄列表那一步）。
客户端刚拉起来、停在登录框或服务器选择界面时是读不到召唤师信息的 —— 先把客户端推进去再点检测。

WeGame 版如果状态一直不对，**完全退出客户端再重开一次**（包括托盘图标），
WeGame 的启动参数在重启后才会刷新。

> 不同的失败提示对应不同的原因，别一律当成「客户端没开」：
>
> | 提示 | 含义 | 怎么办 |
> |---|---|---|
> | 没检测到英雄联盟客户端 | 确实没查到客户端进程 | 打开客户端进到大厅再点检测 |
> | 没能查询客户端进程 | **查询本身失败**（被安全软件或系统策略拦了），不代表客户端没开 | 检查安全软件/公司策略是否拦截了本程序，再点检测 |
> | 找到了客户端但它还没准备好 | 进程在，接口还没起来 | 等 5 秒再点检测 |
> | 客户端重启过、凭据失效 | 端口或令牌变了 | 点检测重试 |
> | 装的是国际服客户端 | 在 `Riot Games` 目录下读到了国际服客户端的 lockfile | 本工具只支持国服客户端 |
> | 连上的不是游戏客户端接口 | 端口被别的程序占了 | 关掉占用端口的程序再试 |
> | 没在常见位置找到客户端 | 装在非标准位置 | 见 Q2 |

### Q2 · 提示「端口失效 / 客户端未运行」

游戏客户端每次重启都会换端口。点一次 **检测客户端** 重新探测即可。

如果提示的是 `Request failed with status code 404`，那是**客户端起来了但还没选好召唤师**，
按 Q1 的办法推进去再试。

如果提示的是「没在常见位置找到客户端」，说明客户端装在了非标准位置 ——
桌面端已经自动全盘扫过一遍还是没找到。确认一下客户端装在哪，
必要时可以把它装到默认位置（WeGame 默认装在 `X:\wegameapps\英雄联盟`）。

### Q3 · 同步码提示「无效或过期」

- 同步码 **5 分钟过期**，重新在小程序里生成
- 同步码 **只能用一次**，兑换失败后码就作废了，重新生成
- **别连续输错**：同一 IP 连错 **5 次会被锁 10 分钟**，提示「尝试次数过多」

### Q4 · 提示「登录已过期，请用同步码重新登录」

桌面端令牌有效期 30 天，过期了或者服务端数据被重置都会这样。
重新走一遍第五节的三步就行 —— **同步码每次都要重新生成**。

### Q5 · 提示「跳过本次同步 / 刚刚已同步过」

后端对同步接口有防刷限频：**相邻两次至少隔 10 秒，60 秒内最多 5 次**。
等十几秒再点一次，不是出错了。

### Q6 · 皮肤数量看着比游戏里少

先看「已拥有皮肤」右边的来源标签。如果是 **「备用来源(降级)」**，
说明库存接口没读到，退到了商城目录 —— 绝版皮肤不会出现在商城里，所以数会少。
重启游戏客户端让它进到主界面，再点「读取我的皮肤」一般能回到蓝色标签。

另外记得：**炫彩、皮肤变体、英雄默认皮肤本来就不计入**，这是有意为之。

### Q7 · 提示「账号已绑定其他 LOL 账号」

首次同步会把「你的小程序账号」和「你当前的 LOL 账号」**一对一绑定**，
之后不能直接换成另一个 LOL 账号（防止库存串号）。

确实要换（比如换了一个大区），**联系管理员解绑**后重新同步一次。

### Q8 · 小程序里数据没变

小程序端的接口有缓存，**下拉刷新**或者退出重进一次。
收藏册里能看到「上次同步」时间，对一下桌面端显示的同步时间就知道是不是同一次。

### Q9 · 皮肤库里有些皮肤没有原画

那是**站内图鉴还没收录**的皮肤。目录补全后会正常显示，不影响同步。

### Q10 · 能同步多个 LOL 账号吗

一个微信小程序账号对应一个 LOL 账号。想要多账号，得用多个微信账号分别绑定。

## 十、对局助手（附加功能）

顶部导航切到 **对局助手**：

- **选人推荐** —— 进入英雄选择阶段后，按你选的位置给推荐
  （需要自己在页面上填一个 **DeepSeek API Key**，用的是 `deepseek-chat` 模型）
- **段位 / 最近战绩** —— 实时拉取，不用额外配置

这一块跟皮肤同步是独立的：不填 API Key 也能用皮肤同步，只是选人推荐不可用。

## 十一、开发者备注

想看技术细节的话：

- 应用本体：[`src/main/`](src/main/)
  - [`lcu/`](src/main/lcu/) —— 跟游戏客户端（LCU）通信
    - [`types.ts`](src/main/lcu/types.ts) —— 失败分类码 + 给用户看的一句话结论（词汇表，改文案只改这里）
    - [`parse.ts`](src/main/lcu/parse.ts) —— 纯解析层：lockfile / 命令行 / 进程名
    - [`channels.ts`](src/main/lcu/channels.ts) —— 发现通道：进程命令行、lockfile、磁盘扫描、路径缓存
    - [`credentials.ts`](src/main/lcu/credentials.ts) —— 裁决层：候选池 → 实测 → 结论
    - [`client.ts`](src/main/lcu/client.ts) —— LCU HTTP 客户端
    - [`lcu.ts`](src/main/lcu.ts) —— 上面这些的统一出口（barrel）
  - [`owned.ts`](src/main/owned.ts) —— 「我拥有哪些皮肤」的口径（库存 ∩ 站内图鉴）
  - [`backend.ts`](src/main/backend.ts) —— 跟服务端同步，含限频与重试
  - [`auth.ts`](src/main/auth.ts) —— 同步码兑换 + 令牌本地加密存储
- 渲染层：[`src/renderer/`](src/renderer/)，Vue 3 + Element Plus
  - 界面上的版本号读的是 [`package.json`](package.json) 的 `version`，
    **不要在代码里再写死一份** —— 写死过一次，结果打包升了版本、界面还显示旧版本号
- 自检：`npm test`（vitest）、`npm run typecheck`、`npm run pack`（出安装包到 `release/<版本号>/`）

### 开发日志控制台

顶栏有个「开发日志」按钮，点它输口令就能开一个底部控制台，实时打印两个进程里
`console.log / warn / error` 的输出，外加未捕获的异常和未处理的 Promise 拒绝。

- 渲染进程的日志从应用启动就开始采集；主进程的日志在主进程里留一份历史，
  打开控制台时一起拉回来 —— 所以**先复现问题、再打开控制台也能看到刚才的报错**。
- 级别可过滤（错误 / 警告 / 信息），「复制」把当前看到的行复制到剪贴板。
- 口令写在 [`src/renderer/src/config/dev.ts`](src/renderer/src/config/dev.ts) 的
  `CONSOLE_PASSWORD`；开发者面板的口令是同文件里的 `DEV_PASSWORD`，两者不是一回事。

### 发版

改 `package.json` 的 `version` → `npm run pack`。
界面上的版本号、诊断信息里的版本号都会自动跟着变，不用再手动同步别处。
本工具**没有自动更新**，用户需要重新下载安装包。

**国内网络打包**：不需要额外操作。`electron-builder.yml` 里配了
`electronDist: node_modules/electron/dist`，打包器直接复用 `npm install` 装好的 Electron，
不联网下载。

> 之前默认行为是从 GitHub 拉 `electron-v<版本>-win32-x64.zip`，国内网络会卡在
> `connect ETIMEDOUT 20.205.243.166:443`。改用本地 dist 就没有这个问题了。
>
> NSIS 工具（`nsis-3.0.4.1` / `nsis-resources-3.4.1`）首次打包会自动下载并缓存到
> `%LOCALAPPDATA%\electron-builder\Cache`，之后就离线可用。
>
> electron-builder 26 改 Windows 资源（版本号、图标）用的是纯 JS 的 `resedit` 包，
> **不再需要** winCodeSign / rcedit —— 不用签名就不会碰它。
